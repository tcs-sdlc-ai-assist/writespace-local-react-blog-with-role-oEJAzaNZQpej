# WriteSpace Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial project setup with Vite, React 18+, and Tailwind CSS
- User authentication system with login, registration, and session management
- Blog post management: create, read, update, and delete functionality
- Admin dashboard with user management capabilities
- Responsive design for all device sizes
- Public landing page with feature highlights and latest posts
- Protected routes for authenticated and admin-only areas
- Local storage-based data persistence for users and posts

### Features
- **User Authentication**: Secure login and registration with session persistence
- **Blog Management**: Full CRUD operations for blog posts
- **Admin Dashboard**: Special admin panel for managing users and viewing statistics
- **Responsive UI**: Mobile-first design with Tailwind CSS
- **Public Landing Page**: Showcase of features and latest posts for visitors

### Tech Stack
- Frontend: React 18+
- Build Tool: Vite
- Styling: Tailwind CSS
- Routing: React Router DOM v6
- State Management: React Context and localStorage
